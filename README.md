# RadarOS Documentation

User documentation for [RadarOS](https://github.com/aakashsengar/agentOs) — a TypeScript-native agent orchestration framework for Node.js.

Built with [Mintlify](https://mintlify.com).

## Local Development

Install the Mintlify CLI:

```bash
npm i -g mint
```

Run the dev server:

```bash
mint dev
```

Open [http://localhost:3000](http://localhost:3000) to preview.

# Introduction

## What is RadarOS?

**RadarOS** is a TypeScript-native agent orchestration framework for Node.js. It provides a complete toolkit for building AI-powered applications—from simple chatbots to complex multi-agent systems—with **zero meta-framework dependency**. Write pure TypeScript, plug in your preferred LLM provider, and ship production-ready agent applications.

RadarOS is designed for developers who want:

- **Full control** over their agent architecture
- **Native TypeScript** without Python runtime or transpilation layers
- **Flexibility** to swap models, storage, and transport layers without rewriting code
- **Production readiness** with built-in session management, memory, RAG, and background job queues

## Why RadarOS?

<Accordion title="vs. LangGraph (Python)">
  LangGraph is Python-only. If your stack is Node.js/TypeScript, you'd need to run a separate Python service, manage two runtimes, and deal with inter-process communication. RadarOS keeps everything in TypeScript—same language, same process, same deployment.
</Accordion>

<Accordion title="vs. Vercel AI SDK">
  The Vercel AI SDK is tightly coupled to Vercel's streaming and React patterns. RadarOS is framework-agnostic: use it with Express, Fastify, Socket.IO, or headless. No vendor lock-in, no React requirement.
</Accordion>

<Accordion title="vs. LangChain.js">
  RadarOS avoids the abstraction overhead of LangChain's chain-based model. You get direct control over the agent loop, tool execution, and session flow—without fighting a complex abstraction layer.
</Accordion>
